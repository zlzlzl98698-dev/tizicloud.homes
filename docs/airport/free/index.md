### 1. 绝对零信任准则

对待任何公开互联网上免费分享的代理节点、订阅源以及不知名开发团队制作的免费客户端，在默认状态下必须将其判定为潜在的不安全信道。绝不能假设节点的提供者出于纯粹的公益慈善动机。在连接免费节点期间，严禁在浏览器中输入任何社交账号、银行卡号、电子邮箱的明文密码，严禁在手机端登录移动网银或进行数字货币钱包授权。免费通道唯一的合规用途，是在断网失联时作为临时应急跳板，去查阅公开资料或拉取正规商业订阅。

### 2. 凭据物理隔离准则

如果必须使用免费节点或免费公开软件，操作应当在完全隔离的计算环境中进行。例如在电脑端开启独立的无痕隐私窗口，或者在虚拟机、备用测试手机中运行相关软件。切勿在日常办公的主力电脑或保存了大量商业机密的主力手机上直接开启全局免费代理。一旦遇到具备中间人攻击能力的恶意蜜罐节点，物理隔离能够有效防止本地存储的 Cookie 凭据、浏览历史与本地局域网端口遭到恶意扫描与窃取。

### 3. 业务权限最小化准则

将网络访问业务划分为不同的安全等级。普通的技术开源代码检索、公开百科词条查阅属于低敏感公开业务；海外跨境电商店铺登录、个人即时通讯、邮件往来属于高度敏感业务。低敏感业务在穷尽安全手段后可以偶尔借助正规商业试用节点完成；而任何涉及商业隐私与资产安全的业务，必须强制走正规企业级独立专线，坚决不允许哪怕一字节的数据流经未知的免费公共网络。

### 1. 免费公开节点的黑客蜜罐机理与中间人攻击剖析

#### 中间人嗅探（MITM）与明文凭据抓取原理

代理服务器在整个网络传输链路中扮演着网关枢纽的角色。当用户开启代理后，手机或电脑产生的所有出网数据包都会首先发送到该服务器，由该服务器解密并转发给目标网站。这一网络拓扑为黑客实施中间人攻击提供了天然的温床，主要表现为三大攻击手法。

- **明文会话与 Cookie 劫持**，虽然绝大多数主流网站已经普及了 HTTPS 加密，但在很多校园网内网登录、学术期刊下载平台以及传统论坛中，依然大量存在基于普通 HTTP 协议的交互。当用户通过免费节点登录这些网站时，部署在代理服务器后端的抓包嗅探脚本（如 tcpdump 或 Wireshark 脚本）能够以毫秒级的速度提取用户提交的明文用户名、登录密码、手机号以及会话 Cookie，并自动回传至黑客的控制数据库。
- **恶意证书注入与深度解密风险**，部分别有用心的所谓免费客户端，在用户安装时会诱导用户授予系统高级管理员权限，并在系统底层悄悄安装一个不受信任的第三方根证书（Root CA）。一旦这个恶意根证书被系统信任，黑客搭建的代理服务器就可以在链路中伪造任意网站的 SSL 证书，实现对用户全部 HTTPS 加密流量的实时解密与窥探，网银密码与私人聊天记录将在攻击者面前彻底裸奔。
- **流量劫持与恶意广告注入**，不法分子利用对代理流量的修改权限，在用户请求的网页 HTML 代码中动态插入恶意弹窗广告、虚假的杀毒软件提示甚至是静默挖矿脚本，利用用户的电脑 CPU 算力在后台挖掘门罗币等虚拟货币。

在海量的免费工具中，由全球著名网络安全巨头 Cloudflare 官方推出的 WARP（1.1.1.1）是极少数不具备任何恶意动机的正规公益产品。然而在大陆网络环境下，它同样面临着严峻的物理现实。

### 代理客户端防御加固与防数据泄露调优实操

在日常配置代理客户端（如 Clash Verge Rev、Clash Meta 或 Surge）时，通过以下三项关键安全设置，能够显著增强终端系统的防御纵深。

#### 1. 坚决关闭“允许来自局域网的连接”（Allow LAN）

在客户端的系统设置面板中，默认情况下务必保持“允许局域网连接”处于关闭状态。很多用户在宿舍、合租公寓或公共咖啡厅办公，如果在公共局域网内开启了该功能，同一 WiFi 网络下的其他未知设备就可以直接通过局域网 IP 将您的电脑当作代理跳板进行数据中转。如果其他受感染设备在从事非法扫描或攻击，您的电脑和本地宽带 IP 将成为直接承担法律责任的替罪羊。

#### 2. 配置规则彻底杜绝 WebRTC 真实本地 IP 泄露

现代主流 Web 浏览器普遍内嵌了 WebRTC 实时通信协议，许多别有用心的网页在检测到用户开启代理后，会通过 WebRTC 的 STUN 穿透探针向目标服务器直接探测用户的真实本地外网 IP 地址，从而使代理的匿名性彻底失效。在客户端的分流规则中，建议加入针对常见 WebRTC 探测服务器（如 `stun.l.google.com`、`stun1.l.google.com`）的直接拦截策略（REJECT），并在浏览器安全插件中彻底禁用 WebRTC 穿透，防止真实 IP 遭到绕过代理的隐蔽刺探。

#### 3. 严格审查订阅配置文件的外部导入权限

### 1. 网上随处可见的免费节点池到底是谁在出钱搭建的？

这些免费节点的出资来源通常主要分为三类。第一类是不法黑客团队与地下黑产数据贩子，他们出资租用廉价服务器搭建节点作为数据抓包蜜罐，通过窃取用户账号凭据与捕获流量进行变现；第二类是部分商业机场为了吸引潜在客户而释放出来的低配置推广试用节点，通过限制速度或配额来吸引用户后续付费；第三类是极少数初学网络配置的技术爱好者搭建的短期实验节点。由于缺乏持续的资金支持，绝大部分公开节点的生命周期极短，且安全性缺乏任何第三方审查。

---

### 2. 使用免费节点浏览 HTTPS 加密的网站，密码真的会被偷看吗？

在正常情况下，HTTPS 协议本身具备端到端强加密特性，代理服务器理论上只能看到用户正在访问的目标网站域名与数据包大小，无法直接解密传输的内容。但是如果用户在安装第三方免费客户端时被诱导信任了恶意的根证书，或者目标网站在特定交互中未强制开启 HSTS 保护（被中间人执行了 SSL 剥离攻击回退至明文 HTTP），黑客依然能够完全捕获明文数据。在恶意蜜罐节点面前，单纯依赖 HTTPS 并不能构成绝对的安全防护。

---

### 3. 为什么很多号称免费试用的机场必须要求绑定个人手机号或邮箱？

这是正规商业机场防范黑产恶意刷取流量的必要风控手段。由于商业带宽采购成本高昂，很多黑产团伙会编写自动化自动化脚本批量注册空头账号，榨干免费试用配额倒卖牟利。要求邮箱验证（甚至限制特定白名单邮箱后缀）或手机验证，能够极大提高恶意批量注册的成本，保障良性真实试用用户的基本体验。在注册试用时，建议使用专门用于注册业务的独立别名邮箱，保护个人主要邮箱免受垃圾邮件骚扰。

---

### 4. 免费节点的 IP 经常被 Google 弹出人机验证（reCAPTCHA）是什么原因？

因为免费公开节点的 IP 地址具有极高密度的滥用历史。成千上万名用户甚至自动化爬虫脚本同时通过该单一 IP 向 Google、OpenAI、Cloudflare 等平台频繁发起高并发请求，该 IP 会被各大互联网巨头的安全风控模型直接打上高危欺诈与异常流量的负面标签。任何通过该节点发起的访问都会被强制拦截并弹出繁琐的人机验证拼图，甚至可能直接被目标网站拉黑阻断访问。

---

### 5. 手机上安装的免费 VPN 软件显示“已连接”，但连不上任何网页怎么回事？

这种现象被称为本地伪装假连。很多劣质免费 VPN 软件在设计上极其粗糙，当点击连接按钮后，软件仅仅在手机操作系统层面建立了一个本地虚拟网卡（VPN 接口），但该接口与境外服务器之间的物理通道实际上早已被防火墙阻断失联。此时手机产生的所有外网请求被强行导向了一个死胡同，不仅导致无法打开外网，甚至连原本正常的国内网络也会被直接阻断。遇到此类情况应立即完全断开连接并卸载该软件。
