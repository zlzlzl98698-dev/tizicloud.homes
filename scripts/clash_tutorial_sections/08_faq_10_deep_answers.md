## 💬 常见长尾技术问题深度解答

为了让新手用户在遭遇网络异常时具备快速排错的能力，本章汇总了在使用各类 Clash 客户端过程中最常见的十个典型疑问并给出权威技术解答。

### Q1 为什么有时候电脑开机后连百度都打不开，必须先打开代理才能上网？

这是由于上一次关机时未正常退出代理客户端，导致操作系统底层的系统代理开关发生残留。在客户端开启系统代理时，Windows 注册表会自动将网络出站定向到本地的专用端口。若在未关闭代理前强行关机，下次开机时由于客户端并未启动，浏览器向该本地端口发送数据全部无应答。解决该问题只需重新启动代理客户端并正常退出，或者进入 Windows 系统的“设置” ➔ “网络和 Internet” ➔ “代理”，将“使用代理服务器”手动拨动为关闭状态即可瞬间恢复。

### Q2 规则模式和全局模式在日常看视频与办公时究竟该怎么选择？

绝大多数日常场景必须坚定不移地选用 Rule 规则模式。在规则模式下，分流引擎会自动识别目标网站归属地，国内访问自动走本地高速通道，只有境外受阻网站才走加密代理节点。全局模式则会不加区分地将所有流量无论境内境外全部送往海外，这不仅会导致国内网页打开缓慢、耗尽机场昂贵的流量配额，更可能触发国内网银或社交软件的异地登录冻结风控。全局模式仅建议在怀疑特定冷门海外网站未被现有规则覆盖时用于临时验证。

### Q3 开启了系统代理，但为什么在终端中使用 Git 或 npm 依然频繁报错超时？

这是由于命令行终端工具与通用网页浏览器在网络通信机制上存在本质差异。网页浏览器会自动遵循操作系统的全局代理环境变量，而 Git、npm、pip 以及 Docker 等专业开发工具默认直接调用底层的操作系统网络套接字，完全无视系统的代理设置。彻底解决这一痛点的方案是在客户端中安装系统服务模式并开启 TUN 虚拟网卡模式，利用三层虚拟适配器直接从网卡层接管终端外发的全部数据包，无需再手动配置繁琐的终端环境变量。

### Q4 为什么某些国内软件在开启代理后提示区域版权限制或网络错误？

该故障通常是因为这些国内应用程序的通信域名未被正确识别为直连，或者你的分流模式被误选为了 Global 全局模式。当这些受版权保护的国内流媒体平台检测到你的出站 IP 属于境外机房时，会自动判定为跨区访问并弹出版权封锁拦截。应对策略是首先检查当前是否处于 Rule 规则模式，随后进入软件的“连接”面板，观察该应用发起请求时命中哪条规则，必要时通过扩展配置将该应用域名手动追加进 DIRECT 直连白名单即可完美解决。

### Q5 在代理面板中点击批量测速，显示的毫秒延迟数值究竟代表什么？

界面上的节点测速延迟，通常是通过向特定的远端公共端点发送极小的 HTTP 握手请求测算出的单次往返耗时。该数值仅代表本地电脑到达该代理服务器物理链路的握手反应敏捷度，完全不等于长周期大带宽持续传输的上限。一个测速仅有数十毫秒的节点，如果处于高峰超卖状态，在实际下载大文件时依然可能发生严重丢包。在选购和评价节点品质时，应当重点考量晚高峰极端网络环境下的真实吞吐带宽与丢包率。

### Q6 如何在局域网内共享当前电脑的代理，让手机或智能电视顺畅上网？

在客户端主界面的通用设置中，找到并开启“允许局域网连接”（Allow LAN）开关。随后打开系统的命令行窗口，输入 `ipconfig` 查看当前电脑在局域网内的真实 IPv4 地址（例如 192.168.1.100）。接着在手机或电视盒子的 Wi-Fi 高级设置中，将代理类型修改为“手动”，代理服务器主机名填入该电脑 IP 地址，端口填入客户端默认的混合端口（通常为 7890）。只要确保电脑不进入深度休眠，局域网设备即可无缝共享出海网络。

### Q7 安装服务模式时，Windows 系统弹出错误或指示灯一直显示灰色怎么办？

服务模式安装失败通常是由本地安全杀毒软件的特权拦截或者旧版本残留服务冲突导致的。首先应当确保你使用的是操作系统的 Administrator 本地管理员账户，并在安装前暂时退出具有强行拦截驱动安装功能的第三方安全卫士。如果问题依旧，可以按下快捷键 Win 加 R 输入 `services.msc` 打开系统服务管理器，在列表中寻找名为 `clash_verge_service` 的旧服务项手动删除。重启电脑后再在客户端中点击安装通常能够顺畅通过。

### Q8 开启 TUN 模式后，局域网内的打印机或群晖 NAS 为什么突然无法访问了？

这是由于 TUN 虚拟网卡的高级路由策略强行接管了原本属于本地私有局域网的数据报文。要恢复局域网设备的顺畅通信，需要在客户端的 TUN 高级配置中，将 `192.168.0.0/16`、`10.0.0.0/8` 以及 `172.16.0.0/12` 等私有保留网段严格加入绕过列表（route-exclude-address-set）中。同时在主规则列表顶部手动加入针对局域网 IP 的 DIRECT 直连指令，这样发往内网共享设备的数据就会直接通过本地物理路由器通信而不被虚拟网卡拦截。

### Q9 代理软件长期在后台运行，会产生大量日志导致固态硬盘损耗吗？

在默认的正常运行模式下绝对不会。正规客户端在发布时默认将日志输出级别设定为 Info 或 Warning，仅在内核发生严重的连接中断或崩溃时才向磁盘写入极微小的错误片段，日常运行时的绝大部分网络转发全都在内存中完成，对硬盘的读写磨损完全可以忽略不计。但需要注意切勿在生产环境中长期开启 Debug 深度排错级别，因为 Debug 模式会记录每一个数据包的详细报文头，不仅白白耗费磁盘存储，更存在个人隐私外泄的潜在隐患。

### Q10 为什么某些境外网站在电脑上打不开，但切换到手机上却能正常访问？

这种平台差异通常源于电脑浏览器与手机端不同的 DNS 缓存以及扩展插件的干扰。首先电脑浏览器的本地 DNS 缓存可能在开启代理前已经记住了被污染的错误 IP，此时可在浏览器地址栏清除内部 DNS 缓存或者重启浏览器。其次是某些电脑浏览器安装了具备代理控制权的第三方翻译或广告屏蔽扩展，这些扩展可能会覆盖系统的全局代理规则。最后应核对电脑客户端的规则库更新时间，确保分流规则集与手机端保持同步更新。
