## 🛠️ 从零上手到高效运行的五步实操路线图

对于刚刚接触该代理生态的用户，面对繁琐的参数面板难免感到无从下手。本章精心梳理了从空白环境安装到全平台平稳运行的五个标准化操作步骤，帮助使用者在几分钟内建立起稳固的出海网络环境。

```
[ 第一步：纯净安装与初次启动 ] ──▶ [ 第二步：导入订阅与节点测速 ] ──▶ [ 第三步：模式锁定与策略选择 ]
                                                                                │
[ 第五步：防断网设置与开机自启 ] ◀── [ 第四步：安装服务与激活 TUN ] ◀───────────┘
```

### 第一步 客户端纯净安装与初次启动环境准备

根据操作系统的具体版本，从官方可信源头下载对应的安装包并完成部署。

启动软件后，首先进入客户端的“设置”界面。建议勾选“随系统启动”以及“静默启动”选项，这样电脑每次开机后客户端会自动常驻在右下角系统托盘中，避免每次手动点开的繁琐。同时，检查客户端界面的语言设置，切换为简体中文以便于后续功能的直观辨识。

### 第二步 导入机场订阅链接并完成批量测速

节点订阅是代理客户端正常运行的数据基石。

1. 进入左侧的“订阅”功能面板，点击右上角的新建按钮，选择类型为“Online”。
2. 将服务商后台提供的订阅链接完整粘贴至 URL 输入栏中，并为该配置起一个便于区分的名称。
3. 点击保存后，观察订阅卡片下方是否正确显示更新时间与文件大小。
4. 切换至“代理”面板，点击右上角的闪电或测速图标，对所有节点发起批量连通性探测。列表将以鲜艳的颜色标出每个节点的真实往返毫秒数，方便使用者挑选可用线路。

### 第三步 锁定 Rule 规则模式并合理设定出站策略

绝大多数日常场景下，切忌滥用全局模式。

在客户端顶部或者设置菜单中，将代理模式明确固定在“Rule”或“规则”选项上。随后进入代理面板，展开“节点选择”或“PROXY”主策略组。对于追求速度的用户，可以选择将策略指向名称带有“自动选优”或“URL-Test”的子组，让核心自动将流量导向当前响应最快的服务器；对于需要进行店铺运营或特定跨国业务的用户，则应当手动点选一个固定的香港或日本专线节点。

### 第四步 安装服务模式并激活 TUN 全局网卡

为了解决各类桌面游戏客户端、命令行开发工具不走代理的痼疾，必须赋予内核底层网络特权。

在“设置”面板中定位至“服务模式”，点击右侧的齿轮图标唤起安装浮窗。点击“安装”按钮，并在操作系统弹出的 UAC 提权确认框中点击允许。观察服务状态图标由灰色转变为鲜绿色，表明特权网桥已在后台正常常驻。随后返回主菜单将“TUN 模式”总开关拨动至开启状态，此时整台电脑的三层网络流量已被完全纳入代理核心的监管之下。

### 第五步 连通性自测与开机防断网终审检查

完成所有核心设置后，必须执行标准的三项健康体检以排除隐患。

<div class="tz-table-wrap">

| 自检测试环节 | 具体测试动作 | 正常预期表现 | 异常排查方向 |
| :--- | :--- | :--- | :--- |
| **基础跨国穿透** | 在浏览器中打开国际知名搜索站点 | 页面毫秒级秒开，连接面板显示请求命中 PROXY 规则 | 检查节点测速是否超时，确认订阅链接未过期 |
| **本土访问免打扰**| 打开国内主流视频或电商门户站点 | 页面秒开无卡顿，连接面板显示请求命中 DIRECT 直连 | 检查分流模式是否误选为 Global，切回 Rule 模式 |
| **休眠断网自愈测试**| 将电脑盒盖休眠三分钟后重新唤醒 | 唤醒后十秒内网络正常恢复，无需手动重启代理软件 | 检查服务模式是否保持运行，排查系统电源节能策略 |

</div>

只要按照上述五步规范完成调试，当前系统便拥有了兼顾极速响应、智能分流与高鲁棒性的网络代理工作环境。
