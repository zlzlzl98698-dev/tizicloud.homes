## 🎯 订阅高效管理的三大黄金铁律

为保证本地代理配置兼具极高抗干扰能力与自动化运维特性，必须严格恪守以下三项管理准则。

### 1. 强制设定定时更新与本地缓存容灾

许多新手用户习惯在导入订阅后便长期置之不理，直到某天节点全部超时才仓促排查。服务商后端的节点 IP 与入口解析域名随时可能根据网络质量实施动态调度。必须在订阅属性中将自动更新间隔设定为合理数值，通常推荐二十四小时更新一次。同时利用客户端自带的本地离线缓存能力，确保即便服务商站点遭遇临时攻击，本地现有节点依旧能够持续无感运行。

### 2. 善用 Script 与 Merge 扩展实现逻辑彻底解耦

直接在下载好的订阅 YAML 文件中手动添加自定义规则是极其低效且脆弱的错误做法。一旦触发订阅更新，所有手工修改的规则行将被云端下发的新文本彻底覆盖清除。正确且唯一推荐的方案是利用客户端自带的扩展配置机制，通过编写简洁的外部规则块或 JavaScript 脚本，在运行时动态将自定义策略注入核心，实现业务规则与上游节点更新的彻底解耦。

### 3. 严禁在公开网络暴露完整订阅 URL

机场订阅链接中包含着使用者的账号唯一识别 Token 与节点连接凭证。一旦该链接在公共技术论坛、截图或者代码仓库中意外泄露，外部人员无需任何密码即可直接同步你的全部节点并消耗你的流量配额。在需要向他人寻求配置排错支持时，必须事先将 URL 中的敏感密文参数彻底抹除。
