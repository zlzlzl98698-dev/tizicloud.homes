### 1. Windows 与 macOS 电脑端：首选 Clash Verge Rev

自原版 Clash for Windows 停更之后，采用现代技术栈重构的 **[Clash Verge Rev](/clash/verge-download/)** 凭借卓越的性能与精美的现代化界面，成为当前桌面端无可争议的首选工具。
* **为什么弃用老版工具**：老旧客户端内存消耗动辄数百兆，且无法原生解析 VLESS Reality 与 Hysteria 2 等现代协议。Clash Verge Rev 内置由开源社区持续高频维护的 Mihomo 内核，性能开销极低。
* **新手必做的三大关键设置**：
  1. **安装 Service 核心服务并开启 TUN 虚拟网卡**：这能建立系统级虚拟网络设备，强制接管整机所有网络流量，让原本不支持系统代理的命令行工具（Git 与终端）、开发环境以及桌面端游戏无感享受代理加速。
  2. **开启 Fake-IP 并绑定海外加密 DNS**：将 DNS 解析劫持到代理内核处理，从底层彻底解决本地 DNS 污染与解析泄漏隐患。
  3. **设定订阅自动更新周期**：建议将订阅刷新周期设定为 24 小时或 48 小时，确保在服务商维护更换节点域名时能够自动同步，避免突发断连。

### 2. iOS 苹果生态：Shadowrocket（小火箭）的正确配置

受制于苹果应用商店的地域上架政策，大陆区 Apple ID 无法直接搜索下载代理工具。
* **低成本获取路径**：用户只需在苹果官网注册一个免费的美国区 Apple ID，通过电商平台购买 3 美元面值的美区 App Store 礼品卡充值，即可在正规美区商店购买正版 **Shadowrocket（俗称小火箭）**。
* **必须牢记的操作要点**：导入订阅节点后，请将首页的全局路由模式由 Proxy（全局）坚决修改为 **Config（配置/规则模式）**。在该模式下，访问微信、淘宝、网易云等国内服务时直接走本地物理宽带，既不消耗宝贵的机场流量，又彻底杜绝了异地 IP 触发国内银行与支付安全风控的麻烦。

### 3. Android 安卓平台：Clash Meta for Android 与后台保活

安卓平台推荐使用 [Clash Meta for Android](/clash/meta/) 或架构先进的 Sing-box。在安卓设备上使用代理工具，核心痛点在于各大手机厂商深度定制系统激进的后台清理机制。用户必须手动进入系统设置，将代理软件加入系统电池优化白名单并开启自启动权限，锁定后台任务卡片，防止系统在锁屏后杀死网络进程引发网络中断。
